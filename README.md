# Нова глава — Android v0.5.0

Офлайн-first Android MVP на Kotlin + Jetpack Compose.

## Що нового у v0.5

### Метод глави — інтеграція матеріалів автора
- **Я 2.0 · Досьє**: `Я зараз / Я в праймі`, риси героя, почерк поведінки, смисли глави, узори реальності. Після заповнення створюється коротка ранкова вижимка і показується у запуску дня.
- **Знайди Передову**: 6 запитань, фільтр незворотності, 4 категорії Передової, оцінка часової петлі, гра на 3 дні / 20 очок, копіювання заповненого пакета для аналізу AI. Відповідь №6 можна одним натисканням зробити поточною Передовою.
- **Детонатор бажань**: 40 запитань у 4 категоріях, позначки ⚡, замір до/після, 2–3 фінальні бажання та незворотний крок на 72 години. Перше бажання можна перенести у результат поточної глави.
- **Перепрошивка**: бібліотека безпечних дій проти автопілота. На день пропонуються 2 дії з різних категорій; будь-яку можна відразу зробити поточним SWITCH.
- **Норма нового рівня · Фото**: Vision Board розбитий на сфери `Стосунки / Простір / Предмети / Подорожі / Я у своїй справі`; для кожної сцени формується prompt, який можна скопіювати у генератор зображень.

### Інше
- Версія `0.5.0`, `versionCode 5`.
- Дані методів зберігаються локально у SharedPreferences та входять у загальний JSON backup.
- Без реєстрації та без обов'язкового хмарного акаунта.

## Збірка APK у GitHub Actions

1. Завантаж увесь проєкт у репозиторій зі збереженням папок.
2. Перевір шлях `.github/workflows/build-apk.yml`.
3. Відкрий **Actions → Build Android APK → Run workflow**.
4. Після успішної збірки завантаж artifact `NovaGlava-v0.5-debug-apk`.
5. Всередині буде `app-debug.apk`.

## Важливо
Матеріали автора інтегровані як практичні вправи. Формулювання про роботу мозку в оригінальних матеріалах не використовуються як медичні твердження або діагностика. У «Перепрошивці» небезпечні варіанти вправ навмисно не перенесені в рекомендований список.
