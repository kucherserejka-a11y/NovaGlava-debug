# Нова глава — Android v0.4

Нативний офлайн Android-застосунок на Kotlin + Jetpack Compose у пастельному стилі Design 4.

## Що працює у v0.4

- Створення власної глави на 30 / 60 / 90 днів.
- Роль поточної глави, Передова та 3 результати сезону.
- Ранковий запуск дня: стан → власний SWITCH → Передова.
- **Власні SWITCH-дії:** до 6 редагованих сценаріїв проти автопілота.
- **Редаговані щоденні дії Передової** прямо на екрані фокус-сесії.
- Фокус-таймер 25 / 45 / 60 хв.
- **Накопичення всього часу Передової за день** через кілька сесій.
- Вечірній check-out і Evidence: «зробив → отримав → анти-автопілот».
- Evidence з конкретною SWITCH-дією та хвилинами Передової.
- Тижневий звіт.
- **Детальна аналітика фокусу** за 7 / 14 / 30 днів: графік, сума, середнє, найкращий день.
- Vision Board на 6 образів із власними фото телефона.
- Архів завершених глав.
- Android-віджет поточного дня та Передової.
- **Системні Android-нагадування:** окремо ранок і вечір, зі своїм часом; відновлюються після перезавантаження телефона.
- **Backup / Restore у JSON:** глава, Evidence, архів, SWITCH-дії, нагадування та інші локальні налаштування.
- Повністю офлайн, без акаунта і сервера.

## Нагадування

За замовчуванням вимкнені. У `Профіль → Нагадування` можна ввімкнути:

- ранковий запуск дня;
- вечірній check-out;
- власний час у форматі 24 годин.

На Android 13+ застосунок попросить системний дозвіл на сповіщення. Використовується inexact daily alarm, тому Android може трохи зміщувати доставку задля економії батареї.

## Резервна копія

`Профіль → Резервна копія`:

- **Експортувати JSON** — зберігає локальні дані у вибрану папку/Drive;
- **Обрати JSON-файл** — відновлює дані та перезапускає UI.

Фото Vision Board не вбудовуються в JSON. Тексти Vision зберігаються, а фото після перенесення на інший телефон потрібно вибрати заново.

## Онлайн-збірка APK без Android Studio

У репозиторії є `.github/workflows/build-apk.yml`.

1. Створи порожній репозиторій на GitHub.
2. Завантаж **вміст** папки `NovaGlavaAndroid` у корінь репозиторію.
3. Відкрий **Actions → Build Android APK**.
4. Натисни **Run workflow**.
5. Після успішної збірки завантаж Artifact `NovaGlava-v0.4-debug-apk`.
6. Усередині буде `app-debug.apk`.

Debug APK призначений для особистого тестування. Для Google Play потрібні release signing та AAB.

## Основні файли

- `app/src/main/java/ua/novaglava/app/MainActivity.kt` — UI та логіка застосунку.
- `app/src/main/java/ua/novaglava/app/ReminderReceiver.kt` — системні нагадування + відновлення після reboot/update.
- `app/src/main/java/ua/novaglava/app/NovaGlavaWidget.kt` — Android-віджет.
- `.github/workflows/build-apk.yml` — онлайн-збірка APK.
